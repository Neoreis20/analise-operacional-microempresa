# 📊 Análise Operacional para Pequenos Negócios

##  Sobre o projeto

Este projeto nasceu a partir do acompanhamento operacional de um pequeno estúdio de tatuagem que não possuía controle financeiro estruturado.

O objetivo é transformar dados simples do dia a dia em indicadores que ajudem pequenos empreendedores a entender:
- faturamento
- fluxo de clientes
- ticket médio
- ponto de equilíbrio
- consistência operacional

---

##  Objetivo

Criar um modelo simples de análise operacional e financeira que possa futuramente evoluir para:
- dashboards
- automações
- sistema web
- IA para geração de insights

---

##  Indicadores analisados

- faturamento semanal
- ticket médio
- fluxo de clientes
- custos operacionais
- acompanhamento de recebimentos
- análise de agenda

---

##  Principais aprendizados

Durante a análise foi possível perceber que muitos pequenos negócios possuem dificuldade em:
- organizar dados financeiros
- visualizar custos reais
- entender previsibilidade operacional
- separar faturamento de fluxo de caixa

---

##  Próximos passos

- estruturação de dashboard
- automação de relatórios
- análise visual de dados
- integração com IA
- desenvolvimento de MVP web

---

## ⚠️ Observação

Os dados utilizados foram adaptados para fins de estudo e portfólio, preservando informações sensíveis do negócio analisado.
