# Análise Operacional para Microempresa

Projeto de portfólio baseado no acompanhamento de um pequeno estúdio de tatuagem que não possuía controle financeiro e operacional estruturado.

A proposta foi transformar dados simples do dia a dia em indicadores capazes de apoiar decisões sobre faturamento, custos, fluxo de clientes e sustentabilidade do negócio.

## Contexto

O projeto nasceu de uma situação real. O negócio acompanhado precisava entender melhor o próprio funcionamento, mas não possuía uma visão consolidada de:

- faturamento;
- ticket médio;
- quantidade de clientes;
- custos operacionais;
- valores pendentes de recebimento;
- ponto de equilíbrio.

Para preservar a empresa analisada, os dados disponibilizados neste repositório foram adaptados e anonimizados.

## O que foi analisado

- faturamento semanal;
- ticket médio;
- fluxo de clientes;
- custos operacionais;
- recebimentos pendentes;
- evolução entre períodos;
- ponto de equilíbrio;
- consistência operacional.

## Resultado do trabalho

A análise ajudou a organizar informações antes dispersas e transformar registros operacionais em uma visão mais clara do negócio.

Entre os principais aprendizados estiveram:

- faturamento não é o mesmo que fluxo de caixa;
- aumento de clientes não garante aumento proporcional do ticket médio;
- custos precisam ser acompanhados junto com receita;
- indicadores simples já permitem identificar tendências importantes.
